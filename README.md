# מה נבנה סביבי | אשדוד

מפה ציבורית של פרויקטי הבינוי וההתחדשות העירונית באשדוד, בשפה פשוטה, עם הדמיות, סרטונים ומקום לשאלות ולתגובות של תושבים.

## מה יש באפליקציה

**לתושבים** (`/`)
- מפת העיר עם הקו הכחול של כל פרויקט ומתחם
- "עוד בעיר": כל מתחמי ההתחדשות העירונית באשדוד, מהרשימה הממשלתית
- חיפוש כתובת או "המיקום שלי", ורשימה ממוינת לפי קרבה וזמן הליכה
- סינון לפי שלב, סוג ורובע
- כרטיס פרויקט: מסלול השלבים ומה כל שלב אומר לתושב, מספרים, מה השכונה מקבלת, הדמיות בגלריה, סרטונים, קובצי KML ו-PDF
- שאלות ותגובות: תושב שולח בלי הרשמה, התגובה מתפרסמת אחרי אישור, ועם תשובת העירייה
- קישור ישיר לכל פרויקט (`/p/<id>`) לשיתוף

**לצוות** (`/admin`)
- כניסה בסיסמה או בקישור למייל. ההרשאה לפי טבלת `staff` הקיימת בפרויקט ASHDODMAP
- עריכת פרויקט: טקסטים, שלב, מספרים, רובע, מיקום
- העלאת KML או KMZ לגבולות התוכנית, או הצבת נקודה בלחיצה על המפה
- העלאת הדמיות (מוקטנות אוטומטית), סרטונים עד 50MB, קישורי יוטיוב/וימאו, PDF; בחירת תמונה ראשית וסידור
- ייבוא מרובה: קובץ KML עם הרבה תוכניות הופך לטיוטות, עם זיהוי שם ומספר תוכנית
- אישור, דחייה ותשובה לתגובות תושבים
- תצוגה מקדימה של מה שהתושב יראה, ופרסום או הסתרה בלחיצה

## מבנה טכני

- React + TypeScript + Vite, Leaflet עם מפת בסיס של CARTO/OpenStreetMap
- Supabase (פרויקט ASHDODMAP): טבלאות `plan_projects`, `plan_media`, `plan_feedback`, ודלי אחסון ציבורי `plan-media`
- הרשאות ב-RLS: הציבור רואה רק פרויקטים מפורסמים ותגובות מאושרות, ויכול רק להוסיף תגובה ממתינה. כל השאר רק לצוות.
- חיפוש כתובות: OpenStreetMap Nominatim, מוגבל לאשדוד
- פריסה: Vercel, מחובר לענף `main`

הסכמה המלאה: `supabase/migrations/`.

## מקורות נתונים ועמודי תוכנית

- **מתחמי התחדשות עירונית**: `supabase/seed/ur-compounds-ashdod.sql` מייבא ומעדכן את כל המתחמים באשדוד מ-data.gov.il (רשימה, מספרים וסטטוס) ואת הגבולות מהשכבה הממשלתית, דרך פונקציית הקצה `supabase/functions/ur-compounds-ashdod`. רץ בתוך מסד הנתונים, בטוח להרצה חוזרת.
- **עמוד תוכנית** (`/plan/<מספר תוכנית>`, לוכסן הופך למקף): טקסט ב-`plan_projects.story`, ומודל תלת-ממדי מקובץ סטטי (`model_url`) או מטבלת `plan_models`.
  - 603-0811588: `public/plans/603-0811588/` ו-`scripts/build_plan_model.py`.
  - תמל/2022: `supabase/seed/tamal-2022.*` (סיפור, פרטי פרויקט, ובניית המודל מתוך שכבות ה-SHP ו-OpenStreetMap), ונספחים ב-`public/plans/tamal-2022/docs/`.
- רשימת הקבצים לכל מתחם חדש, ומה אפשר להוריד אוטומטית: `CLAUDE.md`.

## הרצה מקומית

```
npm install
npm run dev
```

משתני סביבה אופציונליים בקובץ `.env.example`.

## הוספת איש צוות

המשתמש נרשם ב-Supabase Auth, ואז מוסיפים שורה לטבלת `public.staff` עם ה-`user_id` שלו.
